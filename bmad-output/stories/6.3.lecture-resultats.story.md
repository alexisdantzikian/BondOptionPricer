**Mécanisme.** Le texte reste statique ; la cellule « Chiffres cités » (créée par 6.2, fin de §11, juste avant ce markdown) imprime `CHIFFRES`, `dict` ordonné `{libellé: valeur formatée}` ; la concordance texte / `CHIFFRES` se vérifie **hors notebook** par un script jetable, non commité [Source: architecture.md#ADR-009]. Règles de calcul des entrées (héritées de 6.2) : noms publics seulement (dont `res`, `fwd`, `mc`, `mcs`, `scen_repo`, `scen_sy`, `scen_rho`, `scen_ay`, `opts`, `m_cal`, `GMM`, `AR1`, `RHO_MIN`, `RHO_MAX`, `est`), jeu retenu `p_cal`, jamais `p_test`, aucun nombre recopié, helpers `_fr` / `_plage` existants [Source: stories/6.2.cellule-chiffres-cites.story.md#dev-notes] [Source: architecture.md#ADR-002].

**État des entrées au départ (avant réécriture).** La cellule contient les 33 entrées de l'inventaire de l'addendum, calculées sur les sorties actuelles. Plusieurs deviennent sans objet ou changent de définition :
- entrée « spread repo du cas central » (« +5 bp ») : sans objet avec la courbe de marché ; la remplacer, si le texte en parle, par le spread repo de marché à 1 an (`repo.s(1.0)`) ;
- entrées repo −25 / +15 bp : depuis 5.2, les scénarios repo sont des **translations parallèles** de la courbe retenue de −25, −10, 0, +10, +25 bp, plus « financement au taux de l'OAT » ; réécrire les entrées et le texte sur ces scénarios (par ex. « entre −25 et +25 bp ») [Source: architecture.md#ADR-008] ;
- entrée a_y intermédiaire : depuis 8.2, `scen_ay` contient la vitesse AR(1) **corrigée** de la fenêtre 2021-2026 si elle est non nulle, sinon a_y = 0,2, avec un libellé qui le dit [Source: architecture.md#ADR-010].

**Affirmations qualitatives à revérifier** (texte actuel → sortie à lire) [Source: main/oat_option_pricer.ipynb §11, Lecture des résultats] [Source: addendum.md#fr-015] :
- a. Le forward clean baisse avec l'échéance (portage positif d'une OAT financée en repo) → `fwd`, ligne centrale, ou `res["F clean"]`.
- b. Le recentrage $\delta$ croît avec l'échéance (de −1 bp à ≈ 590 bp aujourd'hui) → `opts[T0].delta`, tableau §10.
- c. À 1 an le spread repo pèse peu ; aux longues échéances la fourchette de scénarios change fortement le call ; le financement au taux de l'OAT est une borne haute → tableau « call au strike du cas central selon le spread repo ».
- d. Le spread apporte une part de variance stable selon l'échéance (vitesses de retour faibles) ; $\rho > 0$ rend le terme croisé positif (« le spread s'élargit quand les taux montent ») → `res` colonnes `part spread`, `part croisée` ; signe de `p_cal.rho`.
- e. Le facteur spread renchérit le call ATM d'un pourcentage quasi constant à toutes les échéances → `res["2F / taux seul - 1"]`.
- f. Doubler / diviser par deux $\sigma_y$ : effet asymétrique → `atm_table(scen_sy)`.
- g. $\rho$ est le paramètre le moins bien connu → fourchette `RHO_MIN`–`RHO_MAX` **et** écart-type GMM de $\rho$ (`GMM["se"]["rho"]`) ; dire laquelle des deux incertitudes est la plus large.
- h. À volatilité observée égale, la vitesse de retour change peu les prix ; seul un retour rapide les réduit → `atm_table(scen_ay)` ; mentionner que la vitesse historique corrigée du biais est compatible avec $a_y \approx 0$ (§9.4, `AR1`) [Source: prd.md#FR-020].
- i. Monte-Carlo : poids recentrés dans l'IC à toutes les échéances ; poids en 0 → ≈ 2 % à 10-12 ans ; hors de la monnaie à 5 ans, 1,5 % (call 110 %) et 2 % (put 90 %) ; profil : call ATM maximal vers 5 ans, $\bar\Sigma_B$ maximal vers 7 ans → tableaux §10 et `res`.
