  ```python
  DONNEES = next(p for p in [Path("../data"), Path("data")] if (p / "market data bloom.xlsx").exists())
  FICHIER, FICHIER_REPO = DONNEES / "market data bloom.xlsx", DONNEES / "repo_fictif.csv"

  def load_repo():
      """Spread repo contre €STR par tenor (taux zéro continus), bp -> décimal."""
  ```

  Seule la chaîne `"repo_fictif.csv"` devient `"repo_marche.csv"`. `load_repo` lit les commentaires `#`
  et un fichier UTF-8 : écrire le CSV en UTF-8.
- `tenor_years` : `'1W' -> 1/52`, `'nM' / 'nMo' -> n/12`, sinon `n` années. **Piège** [Inference] : un
  tenor en jours (`1D`) serait lu comme 1 an, et `ON` / `TN` (sans chiffre) font échouer `float("")`. Les

  sur `1W` si l'auteur le valide.
- `repo_curve(curve, T, spread)` interpole linéairement le spread et l'extrapole plat (`np.interp`) ;
  `df(T) = curve.df(T) * exp(-s(T) * T)` [Source: main/oat_option_pricer.ipynb §8 B]. Le spread du CSV
  est donc un spread de **taux zéro continus** contre la courbe €STR `curve`.
- La cellule §1 imprime aujourd'hui `Courbe repo (FICTIVE), spread contre €STR en bp : …` ; ce libellé
  est corrigé par 5.3, pas ici (AC #2 : une seule ligne de code) [Source: epics.md#epic-5].

**Conversion d'un taux repo en spread** [Inference]. Si la cotation est un taux repo monétaire $r$
(base ACT/360, durée $d$ jours) : taux zéro continu $z = \frac{365}{d}\ln\!\big(1 + r\,\frac{d}{360}\big)$,
puis spread $= z - \texttt{curve.zero}(d/365)$, en bp. Faire ce calcul dans un script jetable du
scratchpad (qui charge `curve` en ré-exécutant les §1-§2, ou relit les taux €STR du classeur), et
recopier dans l'en-tête du CSV : la base, la formule et la date. Ne pas mettre la conversion dans le
notebook (NFR-006).
