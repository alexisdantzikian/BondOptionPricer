## Story

je veux **énoncer et appliquer explicitement l'hypothèse de financement au-delà du dernier tenor repo coté, et mesurer la sensibilité autour de la courbe de marché**,

**Code existant** [Source: main/oat_option_pricer.ipynb §8 B] :
```python
class repo_curve:
    """Taux repo = taux zéro €STR + spread repo (taux continus) ; spread interpolé linéairement, extrapolé plat."""
    def __init__(self, curve, T, spread):
        self.curve, self.T, self.spread = curve, np.asarray(T, float), np.asarray(spread, float)
    def s(self, T):
        return np.interp(T, self.T, self.spread)
    def df(self, T):                                                     # P^repo(0, T)
        T = np.asarray(T, float)
        return self.curve.df(T) * np.exp(-self.s(T) * T)
```
